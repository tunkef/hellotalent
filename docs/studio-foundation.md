## Runtime Kontratları (Değiştirme!)

- Panel key: `mulakat` (profil.html, switchPanel, hash routing)
- Loader: `window._htLoadMulakat()` (profil-wizard.js lazy-load)
- Data bridge: `window._htYetkinlikData` (profil-yetkinlik.js → profil-mulakatkocu.js)
- Genel teaser: `window._htGenelCoachTeaser()` (profil-mulakatkocu.js → profil-genel.js)
- Coach detail: `window.openCoachDetail()` (global, Genel panel çağırır)
- CSS prefix: `.ig-` (mevcut), `.st-` (Studio-specific eklentiler)
- Screen states: `star_intro` (Studio landing), `role_select`, `lobby`, `competency_intro`, `practice`, `completion`, `session_complete`
- Session persistence: `sessionStorage` (flow state), `localStorage` (star_seen, journal drafts)

## Gelecek Veri Modeli Önerisi

### Phase 2 — İçerik Yönetimi

```sql
-- Performans + HT Bilgiler içerik sistemi
-- Koç içerikleri (coach_posts) ile AYRI tutulmalı — farklı editorial süreç

CREATE TABLE studio_modules (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  section text NOT NULL CHECK (section IN ('performans', 'ht_bilgiler')),
  slug text UNIQUE NOT NULL,
  title text NOT NULL,
  summary text,
  body_md text,           -- markdown içerik
  video_url text,         -- opsiyonel video embed
  thumbnail_url text,     -- kart görseli
  difficulty text CHECK (difficulty IN ('beginner', 'intermediate', 'advanced')),
  duration_minutes int,   -- tahmini süre
  sort_order int DEFAULT 0,
  status text NOT NULL DEFAULT 'draft' CHECK (status IN ('draft', 'published', 'archived')),
  published_at timestamptz,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);

-- Aday ilerleme takibi
CREATE TABLE candidate_studio_progress (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  candidate_id bigint NOT NULL REFERENCES candidates(id),
  module_id bigint NOT NULL REFERENCES studio_modules(id),
  status text NOT NULL DEFAULT 'started' CHECK (status IN ('started', 'completed')),
  completed_at timestamptz,
  score int,              -- opsiyonel quiz/değerlendirme skoru
  created_at timestamptz DEFAULT now(),
  UNIQUE (candidate_id, module_id)
);
```

### Phase 3 — Rozet Sistemi

```sql
CREATE TABLE badge_definitions (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  code text UNIQUE NOT NULL,          -- 'yetenek_first_practice', 'koc_5_articles', vb.
  section text NOT NULL,              -- 'yetenek', 'koc', 'performans', 'ht_bilgiler', 'genel'
  title text NOT NULL,                -- 'İlk Pratik'
  description text NOT NULL,          -- 'İlk yetkinlik pratiğini tamamladın'
  icon_url text,
  tier text DEFAULT 'bronze' CHECK (tier IN ('bronze', 'silver', 'gold', 'platinum')),
  criteria_type text NOT NULL,        -- 'count', 'streak', 'completion', 'milestone'
  criteria_value jsonb NOT NULL,      -- {"action": "practice_complete", "count": 1}
  sort_order int DEFAULT 0,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE candidate_badges (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  candidate_id bigint NOT NULL REFERENCES candidates(id),
  badge_id bigint NOT NULL REFERENCES badge_definitions(id),
  earned_at timestamptz DEFAULT now(),
  UNIQUE (candidate_id, badge_id)
);
```

## Koç vs HT Bilgiler İçerik Altyapısı

| Özellik | coach_posts (mevcut) | studio_modules (önerilen) |
|---------|---------------------|--------------------------|
| Yazar | Dış koçlar (davetli) | HelloTalent iç ekibi |
| Moderasyon | Admin onay süreci | Doğrudan yayın |
| Medya | Kapak görseli + metin | Video + markdown + görsel |
| Kategoriler | 6 sabit kategori | section bazlı (performans / ht_bilgiler) |
| İlerleme | Yok (okuma bazlı) | Tamamlama + skor |
| Rozet | Yok | Evet (badge_definitions ile) |

**Öneri:** Ayrı tablolar, ayrı admin arayüzleri. Koç içerikleri dış uzmanlara ait ve editoryal süreçten geçer. HT Bilgiler iç ekip tarafından doğrudan yönetilir ve ilerleme takibi gerektirir. Ortak bir generic CMS yerine, her birinin kendi domain'ine özgü tablolar daha temiz.

## Rozet Felsefesi

- **Başarı odaklı**, çocuksu değil — perakende profesyoneli hissiyatı
- **Aksiyona bağlı**: tamamlama, pratik, uygulamalı öğrenme, tutarlılık
- **Tier sistemi**: bronze → silver → gold → platinum (derinlik arttıkça)
- **Örnek rozetler:**
  - İlk Pratik (Yetenek — 1. yetkinlik pratiği tamamla)
  - Haftanın Öğrencisi (5 ardışık gün Studio ziyareti)
  - KPI Ustası (Performans — tüm KPI modüllerini tamamla)
  - Koç Takipçisi (Koç — 10 makale oku + beğen)
  - Profil Şampiyonu (HT Bilgiler — profil optimizasyon rehberini tamamla)
- **Yüzeyleme:** Profil kartı, aday preview drawer, işveren görünümü
